Dos blocos para o código

          
Se você já programa com blocos, você já pensa como programador. O código é a mesma ideia, só que escrita. Passe o dedo (ou o mouse) nos blocos:

“Os blocos são as rodinhas da bicicleta. O código é quando você sai pedalando sozinho.”Guardinho, o cavaleiro da VanCode

          


          
Por que trocar os blocos pelo código?

          

            
Mais poder
Com código você usa tudo que o robô sabe fazer: matemática, sensores, controle preciso e bibliotecas prontas.

            
Mais rápido
Copiar, colar, buscar e trocar. Aquela “sopa de blocos” enorme cabe em poucas linhas de texto.

            
Coisa de campeão
Equipes de ponta do FTC programam em Java para fazer autônomos precisos com sensores, encoders e visão.

            
Pra vida toda
Python e Java estão entre as linguagens mais usadas do mundo: games, apps, sites e inteligência artificial.

            
Você entende de verdade
Os blocos escondem o código. Escrevendo, você sabe exatamente o que o robô está fazendo.

            
Time mais forte
Código em texto é fácil de compartilhar, revisar e guardar versões junto com toda a equipe.
